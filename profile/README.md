## 이젠 팝업 찾지 마세요, 오늘 갈 팝업 PICK 해드릴게요

팝업은 열리는 곳과 기간, 예약 방식이 제각각이라 갈 곳을 고르고 동선을 짜는 데 시간이 듭니다.

**팝픽**은 온보딩에서 고른 취향으로 서울 팝업을 추천합니다.
<br />
날짜와 지역, 시작 시각을 고르면 AI가 하루 방문 코스까지 짜 줍니다.
<br />
만든 코스는 구글 캘린더로 내보낼 수 있습니다.
